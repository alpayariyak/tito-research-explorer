# TITO research explorer

Public site: https://alpayariyak.github.io/tito-research-explorer/

A static interactive guide to token-memory drift, exact call capture, proposed training layouts, and the research evidence. All interactions run locally in the browser.

See [sources and limitations](sources.html), [curated data](research-data.json), and the [downloadable guide](tito-explorer.html). This repository contains the public edition only.
